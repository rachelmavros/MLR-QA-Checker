Load files

Only the submission document is required. Add whichever engine exports you have — ad copy, keywords, extensions, any combination, or all three — and the check runs on what's loaded. Each file is identified by its own contents, so order doesn't matter. Keep the submission document as .xlsx: red highlighting marks rejected assets, and that formatting is lost if it's saved as CSV.

Confirm mapping

One row per ad group found in whichever exports you loaded. The submission document is organised by theme, the engine by campaign and ad group, so each ad group needs both an approved keyword theme and an approved ad theme. Suggestions come from measuring content overlap, not names. The two count columns update as you change a selection — they are the live answer, so you can tune the mapping until the numbers make sense before running the full check.
